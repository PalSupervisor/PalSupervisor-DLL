    Commands

    What Are Commands?

    Commands are special text-based instructions that allow server administrators to interact with PalServer in real time. Commands start with a / (customizable in config.json) followed by the command name and optional arguments.

    Who Can Use Commands?

    Commands marked as Admin require the executing player to be listed in admin_steam_ids or authenticated via the REST API. Commands marked as All can be executed by any connected player.

    Command Syntax Guide

    /command_name <required_argument> [optional_argument={default}]

    • <required_argument> → Must be included when executing the command.
    • [optional_argument] → Optional parameter. If omitted, default server value is used.

    Moderation

    /kick

    Syntax: /kick <player> [reason]
    Description: Kick a player from the server.
    Permissions: In-Game Chat, REST API, Admin Only

    Arguments: * <player> [Required] — Target player name or Steam ID (e.g. Smooth, 76561198000000000). * [reason] [Optional] — Text explanation for the kick/ban action.

    Example: 

    /kick Smooth "AFK in spawn"
/kick 76561198000000000

    /ban

    Syntax: /ban <player> [reason]
    Description: Permanently ban a player.
    Permissions: In-Game Chat, REST API, Admin Only

    Arguments: * <player> [Required] — Target player name or Steam ID (e.g. Smooth, 76561198000000000). * [reason] [Optional] — Text explanation for the kick/ban action.

    Example: 

    /ban CheaterPlayer "Speedhacking detected"

    /unban

    Syntax: /unban <player/uid/ip>
    Description: Remove a ban on a player UID or IP address.
    Permissions: In-Game Chat, REST API, Admin Only

    Arguments: * <player/uid/ip> [Required] — Parameter: player/uid/ip

    Example: 

    /unban 76561198000000000

    /banlist

    Syntax: /banlist
    Description: Display list of all banned players.
    Permissions: In-Game Chat, REST API, Admin Only

    Arguments: * None

    Example: 

    /banlist

    /whitelist

    Syntax: /whitelist <on|off|add|remove|list> [player]
    Description: Manage server whitelist access control.
    Permissions: In-Game Chat, REST API, Admin Only

    Arguments: * <on|off|add|remove|list> [Required] — State toggle ('on' or 'off'). * [player] [Optional] — Target player name or Steam ID (e.g. Smooth, 76561198000000000).

    Example: 

    /whitelist <on|off|add|remove|list> [player]

    /warn

    Syntax: /warn <player> <message>
    Description: Send a formal warning and record a violation.
    Permissions: In-Game Chat, REST API, Admin Only

    Arguments: * <player> [Required] — Target player name or Steam ID (e.g. Smooth, 76561198000000000). * <message> [Required] — Message string to broadcast or send to player.

    Example: 

    /warn <player> <message>

    /freeze

    Syntax: /freeze <player> [seconds]
    Description: Disable player input. 0 = until /unfreeze.
    Permissions: In-Game Chat, REST API, Admin Only

    Arguments: * <player> [Required] — Target player name or Steam ID (e.g. Smooth, 76561198000000000). * [seconds] [Optional] — Duration in seconds (0 = permanent / until manual unmute).

    Example: 

    /freeze <player> [seconds]

    /unfreeze

    Syntax: /unfreeze <player>
    Description: Re-enable input for a frozen player.
    Permissions: In-Game Chat, REST API, Admin Only

    Arguments: * <player> [Required] — Target player name or Steam ID (e.g. Smooth, 76561198000000000).

    Example: 

    /unfreeze <player>

    /mute

    Syntax: /mute <player> [seconds]

    Permissions: In-Game Chat, REST API, Admin Only

    Arguments: * <player> [Required] — Target player name or Steam ID (e.g. Smooth, 76561198000000000). * [seconds] [Optional] — Duration in seconds (0 = permanent / until manual unmute).

    Permissions: In-Game Chat, REST API, Admin Only

    Arguments: * <player> [Required] — Target player name or Steam ID (e.g. Smooth, 76561198000000000). * <x> [Required] — World coordinate axis X (in Unreal Engine centimeters). * <y> [Required] — World coordinate axis Y (in Unreal Engine centimeters). * <z> [Required] — World coordinate axis Z (in Unreal Engine centimeters). * or [Required] — Parameter: or * <player> [Required] — Target player name or Steam ID (e.g. Smooth, 76561198000000000). * <destplayer> [Required] — Target player name or Steam ID (e.g. Smooth, 76561198000000000).
