    Installation Guide

    PalSupervisor requires no external mod loaders, UE4SS, or complex dependencies.

    Step 1: Deploy version.dll

    Copy version.dll directly next to the PalServer binary: 

    PalServer\Pal\Binaries\Win64\version.dll

    Step 2: Configure config.json

    Place your customized config.json in the same directory: 

    PalServer\Pal\Binaries\Win64\config.json

    Example configuration: 

    {
  "version": "0.4.1",
  "chat": {
    "command_prefix": "/",
    "enable_chat_commands": true,
    "admin_steam_ids": [
      "76561198000000000"
    ]
  },
  "api": {
    "enabled": true,
    "port": 27020,
    "bind_address": "0.0.0.0"
  },
  "anticheat": {
    "speed_check": true,
    "stamina_check": true,
    "auto_ban_threshold": 5
  },
  "janitor": {
    "enabled": true,
    "sweep_interval_minutes": 30
  }
}

    Step 3: Launch Server

    Start your dedicated server normally: 

    PalServer-Win64-Shipping-Cmd.exe
    PalSupervisor will initialize automatically upon server startup.

    Step 4: Verify

    Type /help in in-game chat or visit http://127.0.0.1:27020/health in your browser.
