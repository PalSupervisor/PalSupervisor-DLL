    Embedded REST API Reference 🌐

    PalSupervisor embeds a native high-performance, non-blocking HTTP server listening on port 27020 (customizable in config.json). The API allows server management dashboards, Discord bots, and remote administrative tools to monitor and control PalServer with zero tick degradation.

    Authentication & Security

    Administrative endpoints require authentication via one of the following methods:

    1. Header X-API-Key: Matches the api.api_key configured in config.json (Default: changeme-admin-key).
    2. Header Authorization: Bearer <token>: JWT session token obtained from POST /auth/login.

    Example request: 

    GET /api/players HTTP/1.1
Host: 127.0.0.1:27020
X-API-Key: changeme-admin-key

    1. System Health & Performance Metrics

    Method Endpoint Description Auth
    GET /health Server heartbeat, uptime, FPS, tick rate, and supervisor version. Public
    GET /metrics Detailed performance metrics, memory consumption, and active entity counts. Public
    GET /server/stats Real-time player counts, day/night world clock, and loaded actors. Public
    GET /server/license Returns current license tier, hardware ID binding, and validity period. Public
    GET /api/license Alias for /server/license. Public
    POST /auth/login Authenticate with administrator password to receive a session token. Public
    GET /debug/gobjects Returns summary count of currently loaded Unreal Engine GObjects. Admin

    2. Spatial Live Map & World Entity Radar 🗺️

    PalSupervisor provides high-speed spatial entity scanning across the entire Palworld map. All entities return dual-coordinate formatting: * location: Exact Unreal Engine 3D world vector (x, y, z in centimeters). * game_coords: In-game calibrated map grid coordinates (x, y, z matching the player HUD map).

    Map Endpoints

    Method Endpoint Description
    GET /api/map/entities Scans all world entities. Query params: ?type=all\|loot\|deathbags\|pals\|treasures\|chests\|supplies\|wildbuilds\|eggs and ?filter=<text>.
    GET /api/map/loot Returns all loose dropped ground items, quantities, and coordinates. (Alias: /api/map/drops).
    GET /api/map/deathbags Returns all player death corpse bags, containing PlayerUID, SteamID, items list, age, and location.
    GET /api/map/pals Returns all dropped or wild Pal sphere actors. (Alias: /api/map/droppedpals).
    GET /api/map/treasures Returns all world treasure chests, rank levels, and locations.
    GET /api/map/chests Returns all dungeon and open-world interactive chests.
    GET /api/map/supplies Returns active supply drop capsules and meteorite crates.
    GET /api/map/wildbuilds Returns all player structures built outside designated base camp borders.
    GET /api/map/eggs Returns all wild Pal eggs.
    POST /api/map/recoverbag Recovers a player's deathbag items directly back into their inventory. Payload: {"player_id": "<SteamID or UID>"}.
    POST /api/map/cleardrops Clears dropped ground items. Payload: {"radius": 5000.0, "x": 0, "y": 0, "z": 0}.
    POST /api/map/clearwildbuilds Sweeps wild structures. Payload: {"radius": 5000.0, "unowned_only": true}.
    POST /api/map/cleardeathbags Purges death bags across the map. Payload: {"target": "all", "radius": 0}.
    POST /api/map/triggersupply Forces a supply capsule or meteor drop event. Payload: {"type": "capsule", "x": 0, "y": 0, "z": 0}.

    3. Autonomous Janitor & Sweep Audit 🧹

    The PalSupervisor Janitor autonomously demolishes orphaned wild structures, sweeps ground clutter, and purges abandoned deathbags based on configurable rules.

    Method Endpoint Description
    GET /api/janitor/status Returns Janitor operational status, total sweeps executed, items swept, and last sweep timestamp.
    GET /api/janitor/config Retrieves the current active Janitor configuration.
    POST /api/janitor/config Hot-updates Janitor configuration rules (intervals, cleanup flags, max retention age).
    POST /api/janitor/run Triggers an immediate manual sweep with custom overrides.
    GET /api/janitor/swept Returns the live audit trail of the last 500 swept items (name, count, owner, coords, timestamp).

    4. Guild & Base Camp Management 🏰

    PalSupervisor includes enterprise-tier base camp and guild management with instant disk persistence (ForceSave()).

    Method Endpoint Description
    GET /api/guilds List all guilds, member rosters, admin status, and base camp locations.
    GET /api/guilds/{id} Detailed guild profile, member list, join dates, and base camp telemetry.
    POST /api/guilds/set-leader Appoints a new guild leader. Payload: {"guild_id": "...", "player_id": "..."}.
    POST /api/guilds/{id}/members/promote Promotes a guild member to officer/admin. Payload: {"player_id": "..."}.
    POST /api/guilds/{id}/members/demote Demotes a guild member. Payload: {"player_id": "..."}.
    POST /api/guilds/{id}/members/kick Kicks a player from the guild. Payload: {"player_id": "..."}.
    POST /api/guilds/{id}/members/add Force-adds a player to the guild. Payload: {"player_id": "..."}.
    POST /api/guilds/{id}/blacklist Adds or removes a player from guild recruitment blacklist. Payload: {"player_id": "...", "add": true, "reason": "..."}.
    GET /api/guilds/{id}/audit Returns guild chest interaction audit logs (deposits, withdrawals, item counts).
    POST /api/guilds/{id}/destroy Disbands and permanently dismantles a guild and its structures.
    POST /api/guilds/{id}/rename Renames a guild. Payload: {"new_name": "..."}.
    GET /api/bases List all active base camps, guild owners, building counts, workers, and locations.
    POST /api/bases/{id}/wipe Clean Wipe Base Camp: Empties all chest slots to 0, demolishe all base structure actors, dismantles the PalBox, sweeps ground loot, and flushes save to disk. Zero item spill.
    POST /api/bases/{id}/dismantle Dismantles the PalBox actor of a base camp.
    POST /api/bases/{id}/relocate Relocates a base camp to new world coordinates: {"x": ..., "y": ..., "z": ...}.
    GET /api/bases/{id}/chests Inspects all storage container contents and locked states inside a base camp.
    GET /api/bases/{id}/workers Inspects all worker Pals assigned to the base camp (HP, hunger, sanity, diseases).
    GET /api/bases/{id}/pals Alias for /api/bases/{id}/workers.

    5. Player Moderation & Security 🛡️

    Method Endpoint Description
    GET /players List all online players with coordinates, Steam ID, PlayerUID, ping, and guild.
    GET /players/all List all registered players (both online and offline historical save data).
    GET /players/{uid} Detailed player profile (stats, level, inventory slots, party Pals).
    POST /admin/kick Kicks a player. Payload: {"player": "<UID/Name>", "reason": "<text>"}.
    POST /admin/ban Bans a player. Payload: {"player": "<UID/Name>", "reason": "<text>"}.
    POST /admin/unban Unbans a player. Payload: {"player": "<UID/IP/SteamID>"}.
    GET /bans Returns complete list of banned players and reason metadata.
    POST /admin/mute Chat mutes a player. Payload: {"player": "<UID/Name>", "duration": 300}.
    POST /admin/unmute Unmutes a player. Payload: {"player": "<UID/Name>"}.
    POST /admin/freeze Freezes player position. Payload: {"player": "<UID/Name>", "duration": 60}.
    POST /admin/unfreeze Unfreezes a player. Payload: {"player": "<UID/Name>"}.
    POST /admin/kill Instantly kills a player. Payload: {"player": "<UID/Name>"}.
    GET /violations List all active anti-cheat violation records, severity levels, and detection flags.
    GET /violations/{id} Detailed telemetry and evidence for a specific player violation.

    6. Player Progression, Cheats & Inventory ⚡

    Method Endpoint Description
    POST /admin/give/item Grants items directly to player inventory. Payload: {"player": "...", "item_id": "...", "count": 1}.
    POST /admin/give/exp Grants experience points. Payload: {"player": "...", "exp": 50000}.
    POST /admin/give/techpoints Grants technology or boss tech points: {"player": "...", "points": 10, "type": "boss"}.
    POST /admin/heal Restores full HP, hunger, and sanity. Payload: {"player": "..."}.
    POST /admin/godmode Toggles invincibility godmode. Payload: {"player": "...", "enabled": true}.
    POST /admin/sethp Sets exact current HP. Payload: {"player": "...", "hp": 5000}.
    POST /admin/setsp Sets exact stamina. Payload: {"player": "...", "sp": 1000}.
    POST /admin/inventory/clear Wipes player inventory. Payload: {"player": "...", "clear_equipped": false}.
    POST /admin/inventory/take Deducts specific item quantity from inventory.
    POST /admin/inventory/repair Fully repairs all weapons, armor, and gliders in inventory.
    POST /admin/player/respec Refunds all spent player stat points back to unallocated attribute points.
    POST /admin/player/unlockfasttravel Unlocks all fast travel eagle statues across the map.
    POST /admin/player/lockfasttravel Re-locks all fast travel waypoints.
    POST /admin/player/unlockalltech Unlocks all technology tree craft blueprints.
    POST /admin/player/resetalltech Locks all technology tree craft blueprints.
    POST /admin/player/completepaldex Completes 100% of the player's Paldeck discovery records.
    POST /admin/player/resetpaldex Clears the player's Paldeck entries.
    POST /admin/player/setlevel Sets player level directly (1-65).
    POST /admin/player/resetlevel Resets player level to 1.
    POST /admin/player/setmaxweight Sets max carry weight attribute.
    POST /admin/player/setrelics Sets Lifmunk effigy capture power upgrade level.
    POST /admin/player/triggerwanted Triggers criminal PIDF bounty wanted state.
    POST /admin/player/clearwanted Clears criminal wanted status.
    POST /admin/player/rename Force renames a player character.
    POST /admin/teleport Teleports player to destination coordinates or another player.

    7. Pals & Party Management 🐾

    Method Endpoint Description
    POST /admin/pals/give Grants a Pal species directly into player party or Palbox.
    POST /admin/pals/givecustom Grants custom Pal with specified IVs, passive skills, rank, and attacks.
    POST /admin/pals/givenpc Grants a captured human NPC into party.
    POST /admin/pals/take Removes a Pal from player party or Palbox.
    POST /admin/pals/wipe Wipes all Pals from a player's active party.
    POST /admin/pals/revive Instantly revives all incapacitated Pals in a player's team.
    POST /admin/pals/inspect Returns detailed Pal stats (level, IVs, passives, talents, gender).
    POST /admin/pals/spawnp Spawns a wild Pal directly at player's location.
    POST /admin/pals/spawnw Spawns a wild Pal at world coordinates: {"species": "...", "x": ..., "y": ..., "z": ...}.

    8. Dynamic World Bosses, Encounters & Raids 👑

    Method Endpoint Description
    GET /api/bosses List all world boss spawners, alive/dead state, and coordinates.
    POST /api/bosses/spawn Spawns a boss encounter from template near player.
    POST /api/bosses/spawnw Spawns a boss encounter from template at world coordinates.
    POST /api/bosses/respawn Forces an immediate respawn of an Alpha world boss spawner.
    POST /api/bosses/kill Kills active spawned boss encounters.
    POST /api/custom/spawn Spawns a custom JSON-defined multi-phase encounter near player.
    POST /api/custom/spawnw Spawns a custom encounter at world coordinates.
    GET /api/raids Returns active enemy invasion raids marching towards base camps.
    POST /api/raids/trigger Triggers an immediate raid invasion on a target base camp: {"base_id": "..."}.
    POST /api/raids/cancel Terminates all active enemy raid invasions.

    9. In-Game Broadcasts, Popups & Economy Rewards 📢

    Method Endpoint Description
    POST /admin/broadcast Scrolling system broadcast banner across all players' screens.
    POST /admin/alert Center modal notification dialog sent to a specific player.
    POST /admin/alertall Center modal notification dialog sent to all connected players.
    POST /api/popup Displays styled center modal popup dialog to player.
    POST /admin/command Executes any in-game command string via JSON payload: {"command": "/basewipe ..."}.
    POST /api/reward/item Delivers item reward to player with HUD banner notification.
    POST /api/reward/pal Delivers Pal reward to player with HUD banner notification.
    GET /api/events/stream Server-Sent Events (SSE) live event stream for bot and dashboard monitoring.
    POST /api/world/time Sets world time of day: {"time": 12.0}.

    10. Memory & Reflection Explorer API 🔍

    High-level runtime memory inspection and reflection invoking directly on Unreal Engine objects:

    Method Endpoint Description
    GET /admin/explore/search Search engine GObjects by class or substring: ?query=PalBox&limit=25.
    GET /admin/explore/inspect Inspect UObject memory layout, field offsets, and property values: ?addr=0x....
    POST /admin/explore/invoke Invokes a UFunction directly on a target UObject instance via ProcessEvent.
    POST /admin/explore/exec Runs a dynamic memory execution / script sequence.

    PalSupervisor is an independent native extension for Palworld dedicated servers.
