    REST API Reference

    PalSupervisor embeds a high-performance native HTTP server directly into version.dll within PalServer-Win64-Shipping-Cmd.exe. It allows external web panels, companion bots, automated scripts, and management tools to inspect and control the dedicated server in real time.

    • Base URL: http://127.0.0.1:8212
    • Default Port: 8212 (Configurable in PalSupervisor.json via "rest_api_port")
    • Content-Type: application/json

    Authentication & Security

    PalSupervisor supports three authentication schemes:

    1. X-API-Key Header (Recommended for external panels & bots): 
      X-API-Key: your_secure_admin_key
    2. Bearer JWT Token: Obtained via POST /auth/login: 
      Authorization: Bearer <token>
    3. HTTP Basic Auth: Standard HTTP basic auth header with username admin and configured password: 
      Authorization: Basic YWRtaW46ZGVmYXVsdF9pbnNlY3VyZV9hZG1pbl9rZXk=

    Local Loopback Exemption

    Requests originating from local loopback addresses (127.0.0.1, ::1, localhost) can be allowed automatically depending on your PalSupervisor.json security settings.

    1. Authentication & System Health

    POST /auth/login

    Description: Authenticate credentials and acquire a temporary Bearer JWT token.
    Headers: Content-Type: application/json

    === "API Key Request" 

    {
  "api_key": "default_insecure_admin_key"
}

    === "Username & Password Request" 

    {
  "username": "admin",
  "password": "default_insecure_admin_key"
}

    Response 200 OK: 

    {
  "token": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...",
  "expires_in": 86400
}

    GET /health

    Description: Fast liveness probe for load balancers and watchdog scripts.
    Response 200 OK: 

    {
  "status": "ok",
  "uptime": 142
}

    GET /server/stats

    Description: Live server performance metrics, tick rates, connected player counts, and memory footprint.
    Response 200 OK: 

    {
  "server_fps": 60.0,
  "current_players": 4,
  "max_players": 32,
  "uptime_seconds": 3600,
  "server_name": "My Palworld Server",
  "version": "v0.4.1"
}

    GET /metrics & GET /v1/api/metrics

    Description: Prometheus-compatible plaintext metrics for Grafana monitoring.
    Response 200 OK: text/plain Prometheus metric stream.

    GET /config & POST /config/reload

    Description: Inspect current runtime settings or trigger hot-reloading of PalSupervisor.json without server restart.
    Response 200 OK: 

    {
  "success": true,
  "message": "Configuration reloaded"
}

    2. Server-Sent Events (Real-Time SSE)

    GET /api/events/stream & GET /events/stream

    Description: Persistent HTTP event stream (text/event-stream) keeping external panels synced in real time without polling.
    Headers: Accept: text/event-stream, X-API-Key: ...

    Event Stream Output Example: 

    event: player_join
data: {"player_name":"Ash","player_uid":"00000000-0000-0000-0000-000000000001","steam_id":"76561198000000000"}

event: janitor_sweep
data: {"drops_cleared":14,"save_triggered":true,"wild_builds_cleared":2}

event: weather_change
data: {"preset":"Thunderstorm"}

event: anti_cheat_violation
data: {"player":"CheaterGuy","rule":"SpeedHack","action":"kicked"}

    5. Player Moderation & Management

    POST /admin/kick

    Request Body: {"player": "PalTrainer", "reason": "Disruptive behavior"}
    Response 200 OK: {"success": true, "message": "Player kicked"}

    POST /admin/ban & POST /admin/unban

    === "Ban Request" 

    {
  "player": "PalTrainer",
  "reason": "Speedhacking",
  "ip_ban": true
}
    === "Unban Request" 
    {
  "steam_id": "76561198000000000"
}
    Response 200 OK: {"success": true, "message": "Player banned/unbanned"}

    GET /bans

    Description: List all active Steam ID and IP address bans.
    Response 200 OK: JSON list of ban records.

    POST /admin/freeze & POST /admin/unfreeze

    Description: Disables or enables player movement, rotation, weapon firing, and sphere throwing.
    Request Body: {"player": "PalTrainer"}
    Response 200 OK: {"success": true, "message": "Player frozen/unfrozen"}

    POST /admin/mute & POST /admin/unmute

    Description: Mutes or unmutes a player from in-game chat.
    Request Body: {"player": "PalTrainer"}
    Response 200 OK: {"success": true, "message": "Player muted/unmuted"}

    POST /admin/godmode

    Description: Toggles invulnerability to damage, temperature hazards, and hunger depletion.
    Request Body: {"player": "PalTrainer", "enabled": true}
    Response 200 OK: {"success": true, "godmode": true}

    POST /admin/teleport

    === "By Coordinates" 

    {
  "player": "PalTrainer",
  "x": 10500.0,
  "y": -25000.0,
  "z": 150.0
}
    === "To Another Player" 
    {
  "player": "PalTrainer",
  "target": "AdminBob"
}
    Response 200 OK: {"success": true, "message": "Teleported"}

    POST /admin/heal & POST /admin/sethp & POST /admin/setsp

    Description: Set or restore target player HP and SP.
    Request Body: {"player": "PalTrainer", "hp": 5000}
    Response 200 OK: {"success": true}

    6. Announcements, Popups & Visual Rewards (Vanilla Client Compatible)

    PalSupervisor features visual HUD and modal UI alerts that function on completely vanilla client installs without client-side mods.

    POST /admin/broadcast

    Description: Sends a colored system chat broadcast message.
    Request Body: {"message": "Server restart in 15 minutes."}
    Response 200 OK: {"success": true}

    POST /admin/alert & POST /admin/alertall

    Description: Center-screen warning overlay banner with customizable hex color.
    === "Targeted Alert" 

    {
  "player": "PalTrainer",
  "title": "ADMIN WARNING",
  "message": "Do not build wild structures near Fast Travel points.",
  "color": "#FF0000"
}
    === "Server-Wide Alert" 
    {
  "title": "SERVER EVENT",
  "message": "Double XP Weekend is now active!",
  "color": "#00FF7F"
}
    Response 200 OK: {"success": true}

    POST /api/popup & POST /v1/api/popup

    Description: Displays a centered modal dialog box with formatted multi-line text, emojis, and an [ OK ] confirmation button.
    Request Body: 

    {
  "target": "all",
  "message": "Welcome to our Palworld Server!\nPlease review the rules.\nEnjoy your stay! 🔥"
}
    Response 200 OK: {"success": true, "message": "Popup displayed"}

    POST /api/reward/item & POST /v1/api/reward/item

    Description: Grants items and triggers the native animated acquisition card queue and HUD notification log. Supports internal IDs and display names.
    Request Body: 

    {
  "target": "all",
  "item": "Gold Coins",
  "amount": 500
}
    Response 200 OK: {"success": true, "item": "Money", "amount": 500, "rewarded": 4}

    POST /api/reward/pal & POST /v1/api/reward/pal

    Description: Grants a Pal to party/palbox and displays a visual PalDex capture success notification banner.
    Request Body: 

    {
  "target": "all",
  "pal": "Jetragon",
  "level": 50,
  "rank": 4,
  "shiny": false
}
    Response 200 OK: {"success": true, "pal": "JetDragon", "level": 50, "rank": 4, "rewarded": 4}

    7. Progression, Inventory & Cheats

    Progression & Unlocks
    • POST /admin/player/setlevel — {"player": "PalTrainer", "level": 55}
    • POST /admin/player/resetlevel — {"player": "PalTrainer", "level": 1}
    • POST /admin/player/giveexp — {"player": "PalTrainer", "exp": 50000}
    • POST /admin/player/setmaxweight — {"player": "PalTrainer", "weight": 5000}
    • POST /admin/player/rename — {"player": "OldName", "name": "NewName"}
    • POST /admin/player/unlockmap — {"player": "PalTrainer"} (clears fog of war)
    • POST /admin/player/unlockfasttravel — {"player": "PalTrainer"} (unlocks all statues)
    • POST /admin/player/unlockbarriers — {"player": "PalTrainer"} (clears sanctuary barriers)
    • POST /admin/player/completepaldex — {"player": "PalTrainer"} (100% Paldex unlock)
    • POST /admin/player/unlockalltech — {"player": "PalTrainer"} (unlocks all recipes)
    • POST /admin/player/setrelics — {"player": "PalTrainer", "relics": 10} (sets capture power)

    • POST /admin/inventory/clear — {"player": "PalTrainer", "target": "all"} (all, bags, gear, or keys)
    • POST /admin/inventory/remove — {"player": "PalTrainer", "item": "PalSphere_Legendary", "count": 10}

    8. Guilds & Base Camp Administration

    GET /api/guilds & GET /guilds

    Description: Returns all server guilds with leader details, member counts, and base counts.
    Response 200 OK: 

    {
  "success": true,
  "count": 1,
  "guilds": [
    {
      "guild_id": "A1B2C3D4-0000-0000-0000-000000000001",
      "guild_name": "ApexPredators",
      "master_uid": "00000000-0000-0000-0000-000000000001",
      "master_name": "PalTrainer",
      "member_count": 3,
      "base_count": 2
    }
  ]
}

    GET /api/guilds/:id & GET /guilds/:id

    Description: Full roster, online status, coordinates, and base camp locations for a specific guild.

    Guild Management Endpoints
    • POST /api/guilds/:id/kick — {"player_uid": "..."}
    • POST /api/guilds/:id/transfer_master — {"new_master_uid": "..."}
    • POST /api/guilds/:id/rename — {"new_name": "NewGuildName"}
    • POST /api/guilds/:id/disband — {} (disbands guild and frees territories)
    • POST /api/guilds/cleanup — {"inactive_days": 14} (audits and dismantles inactive bases)
    GET /api/bases & GET /bases

    Description: Returns all player base camps across the entire world map.
    Response 200 OK: 

    {
  "success": true,
  "count": 2,
  "bases": [
    {
      "base_id": "B1B2B3B4-0000-0000-0000-000000000001",
      "guild_id": "A1B2C3D4-0000-0000-0000-000000000001",
      "location": { "x": 14200.0, "y": 8500.0, "z": 450.0 },
      "worker_count": 15,
      "max_workers": 15
    }

}

    GET /api/bases/:id/workers & GET /api/bases/:id/chests
    • GET /api/bases/:id/workers: Assigned base worker Pals (HP, SAN, hunger, debuffs, passives).
    • GET /api/bases/:id/chests: Storage chests, slot usage, and item contents.
    • POST /api/bases/:id/dismantle: Demolishes the target base camp immediately.

    {
  "success": true,
  "count": 1670,
  "entities": [
    {
      "id": "E73CBD32-41BE801A-8092778D-30D5DE15",

    World Cleaners & Bag Recovery

    • POST /api/map/clearwildbuilds — {"radius": 0, "unowned_only": true} (demolishes wilderness structures)

    • POST /api/map/triggersupply — {"meteor": true} (forces instant supply capsule or meteorite impact)

    10. World Bosses, Raids & Environment

    GET /api/bosses & POST /api/bosses/respawn
    • GET /api/bosses: Returns all 254 field, dungeon, and tower boss spawners with live spawned state.
    • POST /api/bosses/respawn: {"boss": "all"} forces instant respawn of bosses by resetting cooldown timers.
    GET /api/raids & POST /api/raids/trigger & POST /api/raids/cancel
    • GET /api/raids: Returns active base raid incidents and remaining timers.
    • POST /api/raids/trigger: {"player": "PalTrainer"} forces an enemy raid march against the target player's base.
    • POST /api/raids/cancel: {} stops and disperses any active base raid.
    GET /api/world/environment & POST /api/world/weather & POST /api/world/time
    • GET /api/world/environment: Current and upcoming atmospheric weather presets.
    • POST /api/world/weather: {"preset": "Thunderstorm"} changes the active weather preset.
    • POST /api/world/time: {"hour": 12, "timescale": 1.0} adjusts server time and time flow speed.

    13. Live Reflection & Unreal Object Explorer

    Allows advanced server developers and panel maintainers to query and invoke Unreal Engine objects dynamically in memory without restarting the server.

    GET /api/v1/explore/search

    Query Parameter: ?query=PalCharacter
    Description: Search loaded game objects and classes across server memory.

    GET /api/v1/explore/inspect

    Query Parameter: ?address=0x18F4A2B0
    Description: Inspect properties, fields, and values of a specific game object.

    POST /api/v1/explore/invoke

    Request Body: {"address": "0x18F4A2B0", "function": "ResetStatus", "params": {}}
    Description: Dynamically invokes a callable function on the target object via reflection.

    14. Universal Command Dispatcher & Official v1 API Compatibility

    Description: Executes any in-game chat slash command directly via the REST API with full textual feedback.
    Request Body:

  "command": "/janitor status"
}
    Response 200 OK: 
    {
  "success": true,
  "command": "/janitor status",
  "response": "[Janitor] Status: Active (Running: Yes) | Cleaned Drops: 142 | Cleaned Builds: 8"
