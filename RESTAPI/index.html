    Embedded REST API Reference 🌐

    PalSupervisor embeds a native high-performance, non-blocking HTTP server listening on port 27020 (customizable in config.json). The API allows server management dashboards, Discord bots, and remote administrative tools to monitor and control PalServer with zero tick degradation.

    Authentication & Security

    Administrative endpoints require authentication via one of the following methods:

    1. Header X-API-Key: Matches the api.api_key configured in config.json (Default: changeme-admin-key).
    2. Header Authorization: Bearer <token>: JWT token obtained from POST /auth/login.

    Example request: 

    GET /api/players HTTP/1.1
Host: 127.0.0.1:27020
X-API-Key: changeme-admin-key

    1. System & Health

    Method Endpoint Description Auth
    GET /health Server heartbeat, uptime, FPS, tick rate, and supervisor version. Public
    GET /metrics Detailed performance metrics, memory consumption, and active entity counts. Public
    GET /server/stats Real-time player counts, day/night world clock, and loaded actors. Public
    POST /auth/login Authenticate with administrator password to receive a session token. Public

    2. Spatial Live Map & World Entity Radar 🗺️

    PalSupervisor provides high-speed spatial entity scanning across the entire Palworld map. All entities return dual-coordinate formatting: * location: Exact Unreal Engine 3D world vector (x, y, z in centimeters). * game_coords: In-game calibrated map grid coordinates (x, y, z matching the player HUD map).

    Dual-Coordinate JSON Format

    {
  "id": "DropItem_12345",
  "type": "DropItem",
  "name": "Wood",
  "count": 50,
  "location": { "x": -123456.0, "y": 234567.0, "z": 1250.0 },
  "game_coords": { "x": -613.0, "y": 781.0, "z": 12.5 }
}

    Map Endpoints

    Method Endpoint Description
    GET /api/map/entities Scans all world entities. Query params: ?type=all\|loot\|deathbags\|pals\|treasures\|chests\|supplies\|wildbuilds\|eggs and ?filter=<text>.
    GET /api/map/loot Returns all loose dropped ground items, quantities, and coordinates. (Alias: /api/map/drops).
    GET /api/map/deathbags Returns all player death corpse bags, containing PlayerUID, SteamID, items list, age, and location.
    GET /api/map/pals Returns all dropped or wild Pal sphere actors. (Alias: /api/map/droppedpals).
    GET /api/map/treasures Returns all world treasure chests, rank levels, and locations.
    GET /api/map/chests Returns all dungeon and open-world interactive chests.
    GET /api/map/supplies Returns active supply drop capsules and meteorite crates.
    GET /api/map/wildbuilds Returns all player structures built outside designated base camp borders.
    GET /api/map/eggs Returns all wild Pal eggs.
    POST /api/map/recoverbag Recovers a player's deathbag items directly back into their inventory. Payload: {"player_id": "<SteamID or UID>"}.

    3. Autonomous Janitor & Sweep Audit 🧹

    The PalSupervisor Janitor autonomously demolishes orphaned wild structures, sweeps ground clutter, and purges abandoned deathbags based on configurable rules.

    Method Endpoint Description
    GET /api/janitor/status Returns Janitor operational status, total sweeps executed, items swept, and last sweep timestamp.
    GET /api/janitor/config Retrieves the current active Janitor configuration.
    POST /api/janitor/config Hot-updates Janitor configuration rules (intervals, cleanup flags, max retention age).
    POST /api/janitor/run Triggers an immediate manual sweep. Payload supports custom overrides (see below).
    GET /api/janitor/swept Returns the live audit trail of the last 500 swept items (name, count, owner, coords, timestamp).

    Manual Sweep Request Payload

    {
  "clean_drops": true,
  "clean_wild_builds": true,
  "clean_deathbags": false,
  "deathbag_max_age_minutes": 120,
  "dry_run": false
}

    Swept Record Audit Response

    {
  "total_swept": 1,
  "items": [
    {
      "timestamp": 1726145600,
      "category": "DeathBag",
      "name": "DeathBag",
      "count": 1,
      "owner_uid": "1A2B3C4D000000000000000000000000",
      "owner_name": "Smooth",
      "location": { "x": -123456.0, "y": 234567.0, "z": 1250.0 },
      "game_coords": { "x": -613.0, "y": 781.0, "z": 12.5 }
    }
  ]
}

    4. Player Moderation & Management 🛡️

    Method Endpoint Description
    GET /players List all connected players with coordinates, Steam ID, PlayerUID, ping, and guild.
    GET /players/all List all registered players (both online and offline historical save data).
    GET /players/{uid} Detailed inspect profile for a specific player (stats, inventory, active pals).
    POST /admin/kick Kicks a player. Payload: {"player": "<UID/Name>", "reason": "<text>"}.
    POST /admin/ban Bans a player. Payload: {"player": "<UID/Name>", "reason": "<text>"}.
    POST /admin/unban Unbans a player. Payload: {"player": "<UID/IP/SteamID>"}.
    POST /admin/mute Chat mutes a player. Payload: {"player": "<UID/Name>", "duration": 300}.
    POST /admin/unmute Unmutes a player. Payload: {"player": "<UID/Name>"}.
    POST /admin/freeze Immobilizes a player. Payload: {"player": "<UID/Name>", "duration": 60}.
    POST /admin/unfreeze Restores player movement. Payload: {"player": "<UID/Name>"}.
    POST /admin/kill Kills a player. Payload: {"player": "<UID/Name>"}.
    POST /admin/wanted Sets wanted bounty level. Payload: {"player": "<UID/Name>", "level": 3}.

    5. Player Cheats & State Modification ⚡

    Method Endpoint Description
    POST /admin/give/item Gives items to player. Payload: {"player": "...", "item_id": "...", "count": 1}.
    POST /admin/give/exp Grants player experience. Payload: {"player": "...", "exp": 50000}.
    POST /admin/give/techpoints Grants technology points. Payload: {"player": "...", "points": 10}.
    POST /admin/give/stats Grants unspent attribute points. Payload: {"player": "...", "points": 5}.
    POST /admin/heal Instantly heals player HP, hunger, and sanity. Payload: {"player": "..."}.
    POST /admin/godmode Toggles invincible godmode. Payload: {"player": "...", "enabled": true}.
    POST /admin/repair Fully repairs all equipped weapons, armor, and inventory tools.
    POST /admin/paldex/complete Unlocks 100% Paldeck discovery entries for player.
    POST /admin/map/unlock Fully clears fog-of-war across the entire map for player.
    POST /admin/teleport Teleports player to coordinates or another player.

    6. Guilds & Base Camps 🏰

    Method Endpoint Description
    GET /api/guilds List all guilds, member rosters, leader, and base camp locations.
    GET /api/guild/info Detailed guild profile by Guild ID or Name.
    POST /admin/guild/rename Force rename a guild. Payload: {"guild_id": "...", "new_name": "..."}.
    POST /admin/guild/setleader Appoints a new guild leader. Payload: {"guild_id": "...", "player_id": "..."}.
    POST /admin/guild/disband Disbands a guild. Payload: {"guild_id": "..."}.
    POST /admin/base/killnearest Destroys the nearest base camp to an admin or coordinate.
    GET /admin/base/chests Inspects all storage container contents inside a base camp.
    GET /admin/base/pals Inspects all working Pals stationed inside a base camp.

    7. Dynamic Bosses, Raids & World Events 👑

    Method Endpoint Description
    GET /api/bosses List all active world bosses, levels, health, and spawn cooldowns.
    POST /admin/boss/spawn Spawns a boss encounter from a template. Payload: {"template": "...", "coords": {...}}.
    POST /admin/boss/respawn Resets cooldown on a world boss. Payload: {"boss_id": "..."}.
    GET /api/raids Returns current active enemy base raids.
    POST /admin/raid/trigger Forces an immediate base raid invasion. Payload: {"base_id": "..."}.
    POST /admin/raid/stop Terminates an ongoing raid event.
    POST /admin/supply/drop Triggers a supply drop capsule or meteor event at coordinates or player.

    8. In-Game Broadcasts & Alerts 📢

    Method Endpoint Description
    POST /admin/broadcast Scrolling system broadcast banner across all players' screens.
    POST /admin/alert Center modal notification dialog sent to a specific player.
    POST /admin/alertall Center modal notification dialog sent to all connected players.
    POST /admin/command Executes any in-game command via JSON payload: {"command": "/help"}.

    9. Proactive Anti-Cheat & Violations 🛡️

    Method Endpoint Description
    GET /violations List all active player violation records, detection flags, and severity counts.
    GET /api/anticheat/logs Query chronological anti-cheat detection logs with filtering.
    POST /api/anticheat/clear Clear violation records for a player or all players.
    GET /api/anticheat/config View active anti-cheat thresholds (speed delta, stamina limit, ban threshold).
