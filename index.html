Core Architecture

Built for High-Stakes Dedicated Servers

Traditional RCON tools are sluggish and rate-limited. PalSupervisor runs directly inside the server process with full access to Unreal Engine CDOs and GameState.

Sub-Microsecond Memory Detours

Hooks into UObject::ProcessEvent and native Kismet libraries without altering game binaries on disk. Suppresses administrative chat noise while executing complex world queries, item drops, and teleports in the same tick.

Zero Tick Impact

Proactive Anti-Cheat Matrix

Detects speed manipulation, infinite stamina, illegal damage spikes, spoofed capture rate packets, and unauthorized fly hacks before they harm other players.

Discord Webhook Logs

Dynamic Boss & Raid Engine

Summon custom multi-tier boss encounters from JSON templates with custom minion waves, scaled hitpoints, custom drop tables, and screen alerts.

Template Driven

Embedded REST API & Web Dashboard

Features a self-hosted non-blocking web server on port 27020. Directly manage players, inspect inventories, send server notices, and trigger backups without relying on laggy RCON protocols.

Deployment

Quick 4-Step Drop-in Setup

No engine patches or third-party injectors needed. PalSupervisor leverages Windows DLL proxy architecture.

01

Deploy DLL

Copy version.dll into the binary directory next to the PalServer executable:

PalServer\Pal\Binaries\Win64\version.dll
02

Configure Server

Place your customized config.json in the same folder to specify Admin Steam IDs & ports.

PalServer\Pal\Binaries\Win64\config.json
03

Start PalServer

Run your dedicated server normally. PalSupervisor initializes automatically on engine startup.

PalServer-Win64-Shipping-Cmd.exe
04

Access Dashboard

Connect via in-game chat with /help or open the executive web panel in your browser:

http://127.0.0.1:27020

Embedded REST API Endpoints
