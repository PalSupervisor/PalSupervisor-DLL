    Features & Architecture

    PalSupervisor operates as an in-process native supervisor and telemetry engine injected directly into PalServer-Win64-Shipping-Cmd.exe via Windows DLL proxy (version.dll).

    1. Engine Detour Hooking & Zero Overhead

    • Direct ProcessEvent Interception: Intercepts Unreal Engine RPCs and execution dispatches before game logic executes them, allowing instantaneous sanitization of malicious packets.
    • No Client Mods Required: Works with 100% standard, unmodded vanilla Palworld game clients.
    • Microsecond Latency: Pure native C++ execution with average detour overhead under 0.02ms.

    2. Proactive Anti-Cheat Engine

    • Movement Heuristics: Multi-tick velocity and delta-position validation detects speed hacks, noclip, illegal flight, and unauthorized teleportation.
    • Stat & Stamina Sanitization: Prevents infinite stamina exploits, out-of-bounds player HP, and impossible stat point distribution.
    • Dev & Debug RPC Interception: Blocks client invocation of developer functions (Debug_InvaderMarch, cheat RPCs) and enforces automatic bans.
    • RPC Flood Rate-Limiter: Throttles network spam and denial-of-service attempts against the server thread.
    • Violation Audit: Full telemetry recording accessible via /violations and GET /violations.

    3. Deep Player Telemetry & Inspection (Online & Offline)

    • Online & Offline Inspection: Scans memory containers and directly accesses player data even when users are disconnected using UPalGroupManager and save file GUIDs.
    • Party Pal Deep-Scan: Species, level, rank, HP, talent IVs (0-100), active/passive skills, and illegal stat detection.
    • Inventory & Durability: Real-time inspection of bag slots, weapons, armor, and equipment with live durability tracking.
    • Location Breadcrumbs: Logs recent 30-point coordinate history to inspect player pathing.

    4. Live Pal Mutator & Player Stat Resetter

    • Zero-Downtime Party Pal Mutator: In-memory editing of party Pals via UPalOtomoHolderComponentBase and FPalIndividualCharacterSaveParameter.
    • Instantly mutate Level (1-60), Rank (1-5), Gender, Nickname, Passives, and IVs (Talent_HP, Talent_Melee, Talent_Shot, Talent_Defense).
    • Triggers immediate network replication to clients via OnRep_SaveParameter without relogging.
    • Player Stat Resetter & Refund:
    • Scans GotStatusPointList, calculates all allocated points, refunds them directly into UnusedStatusPoint, and syncs via client network RPCs.

    5. Guilds & Base Camp Administration

    • Guild Roster Management: Comprehensive guild roster tracking, master assignment, kick, rename, and disbanding.
    • Base Camp Demolition: Remote base camp dismantling frees territory without server downtime.
    • Worker Palbox Telemetry: Inspects all Pals assigned to base work, including current HP, SAN, hunger, depression/fracture debuffs, and passives.
    • Chest Storage Auditor: Lists slot capacities, lock states, and inventory item counts across all base storage containers.
    • Automated Inactivity Pruning: Audits inactive guilds and bases, previewing or automatically dismantling abandoned bases (POST /api/guilds/cleanup).

    6. World Loot & Map Entity Telemetry (1,600+ Objects)

    • Live Entity Scanning: Iterates UPalMapObjectManager across the entire world map with exact $(X, Y, Z)$ coordinates.
    • Tracked Entities:
    • Wilderness treasure chests (Grades 1-5, unopened state, drop tables)
    • Player death bags and corpses with instant remote item recovery
    • Loose item drops on the ground
    • Unowned or wild player structures constructed outside base camp territories
    • Active supply capsules and incoming meteorites

    7. World Bosses, Dungeons & Instant Respawner

    • Complete Boss Enumeration: Scans 254 APalNPCSpawnerBase actors (FieldBosses, DungeonBosses, ImprisonmentBosses, TowerBosses).
    • Live Status Tracking: Coordinates, active/spawned state, respawn cooldowns, and class names.
    • Instant Boss Respawner: Resets spawner cooldowns and triggers SpawnRequest_ByOutside(true) on-demand.

    8. Base Camp Raid & Incident Controller

    • Active Raid Telemetry: Queries UPalInvaderManager for ongoing enemy raids, wave counts, and remaining timers.
    • Manual Raid Spawner: Force-triggers enemy raid marches against any player base camp.
    • Instant Raid Cancellation: Disperses and cancels active enemy raids immediately with server broadcast.

    9. Dynamic Weather & World Environment

    • SkyCreator Atmospheric Control: Direct integration with BP_PPSkyCreatorWeatherPresetController_C.
    • Preset Switching: Switch between Clear, Rain, Thunderstorm, Foggy, and custom twilight presets on-demand.
    • Time Dilation: Set the in-game clock hour (0-24) and time dilation speed (timescale).

    10. Autonomous Background Server Janitor

    • Wild Structure Demolition: Automatically sweeps and cleans unowned or orphaned structures constructed outside base camps to prevent physics engine lag.
    • Ground Drop Cleanup: Periodically clears abandoned ground item drops to preserve server memory and tick rate.
    • Configurable Sweep Intervals: Fully customizable intervals and manual on-demand triggers (POST /api/janitor/run).

    11. Real-Time Server-Sent Events (SSE) Bus

    • Persistent HTTP Stream: High-performance text/event-stream keeping dashboards and Discord bots updated in real-time without polling.
    • Broadcast Events: player_join, player_leave, chat_message, raid_start, raid_end, boss_spawn, janitor_sweep, weather_change, and anti-cheat violations.

    12. Vanilla Client-Compatible Modal Popups & Visual HUD Rewards

    • Native Modal Dialogs: Displays centered modal popup dialogs with formatted text, emojis, and [ OK ] buttons on unmodded vanilla clients.
    • Animated Item Rewards: Triggers the client-side acquisition card queue (WBP_PalIngameMenuItem_GetGroup_C) and HUD notification log.
    • PalDex Banners: Displays capture celebration banners when rewarding Pals to players.

    13. Universal Command Dispatcher & Official v1 API Compatibility

    • Universal Slash Command API: Execute any of the 116 in-game slash commands directly via POST /admin/command or POST /v1/api/command.
    • Drop-In PalServer v1 API: 100% compatible with official tooling (/v1/api/info, /v1/api/players, /v1/api/announce, /v1/api/kick, /v1/api/ban, /v1/api/unban, /v1/api/save, /v1/api/shutdown).

    14. Live Reflection & Unreal Object Explorer

    • Runtime Object Search: Query and inspect UObject instances directly in server memory.
    • Dynamic Property Inspection: View fields, addresses, and values in real time.
    • Remote UFunction Invocation: Safely call game functions dynamically without recompiling the server.

    15. Embedded REST API & Web Panel

    • Integrated HTTP Server: Native embedded server listening on port 8212 (configurable).
    • Multi-Scheme Authentication: Supports X-API-Key, JWT Bearer tokens, and HTTP Basic Auth.
    • Web Dashboard: Included responsive glassmorphic web portal for monitoring and management.
